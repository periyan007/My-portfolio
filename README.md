# My-Portfolio

## Digital Portfolio Form Feature

This portfolio now includes a comprehensive digital form that converts traditional PDF-style forms into a modern, editable web interface.

### Features

- **Personal Information Section**: Full name, email, phone, address with auto-fill functionality
- **Professional Information**: Current position, company, experience, skills, and bio
- **Education Section**: Dynamic education entries with add/remove functionality
- **Projects Section**: Dynamic project entries with descriptions and URLs
- **Social Media & Contact Links**: LinkedIn, GitHub, Twitter, Instagram profiles
- **Career Goals & Aspirations**: Current focus and 5-year goals

### Form Functionality

- **Auto-fill**: Automatically splits full name into first/last name fields
- **Real-time Validation**: Email, phone, and URL validation with visual feedback
- **Dynamic Entries**: Add/remove education and project entries as needed
- **Preview Mode**: View formatted data before submission
- **Draft Saving**: Auto-save and manual draft saving with localStorage
- **Data Export**: Export form data as JSON
- **Responsive Design**: Mobile-friendly layout
- **Form Submission**: Complete form processing with success feedback

### Files Added

- `form.html` - Main form interface
- `form-styles.css` - Form-specific styling that complements the existing design
- `form-script.js` - JavaScript functionality for form interactions

### Access

Visit the main portfolio page and click the "📝 Edit Portfolio Info" button to access the digital form.

### Web Standards Compliance

- HTML5 semantic elements
- ARIA accessibility attributes
- Progressive enhancement
- Mobile-responsive design
- Modern CSS Grid and Flexbox
- ES6+ JavaScript features
